# Bramha.org V12 — Sringeri Sister Clone

This package recreates the Sringeri.net visual rhythm for Bramha.org using original Bramha.org HTML/CSS and Bramha.org assets/content. It does not include Sringeri logos, institutional text, or photographs.

## Included
- Sringeri-style 27px top notice strip
- cream institutional masthead with Bramha.org logo
- compact uppercase navigation with color-coded dropdowns
- orange featured hero with Google Sheet/Supabase-controlled slides
- 1175px three-column resource section
- horizontal announcement cards and thin orange scrollbar
- warm date/knowledge band and institutional footer
- matching site-wide header/footer on inner pages
- Dharma/Gṛhya readers keep verified-public filtering but hide the visible Verified Reference block and reader announcement strip
- Tarabalam calculation logic is untouched

## Deploy
Extract the ZIP and upload the CONTENTS directly to the GitHub repository root. Keep your existing root 1.jpg through 6.jpg files used by Tarabalam.

## Homepage slides
The homepage still reads verified/published Homepage Slide records from Supabase (synced from your Google Sheet setup).
