# Bramha.org UI V10 — Traditional Heritage

This package implements the approved traditional Bramha.org visual direction:

- ornamental cream / orange / gold visual system
- framed temple + manuscript hero
- traditional resource panels
- announcement cards
- date / Panchāṅga-style visual band (date only; no invented Panchāṅga data)
- Sanskrit decorative knowledge strip
- traditional footer
- new Bramha.org logo integrated across the shared UI shell

## Preserved functionality

- Supabase configuration and public verification filters are unchanged.
- Dharma and Gṛhya reader JavaScript is unchanged.
- Tarabalam calculation formula, five-language dataset and matrix logic are unchanged.
- Existing routes remain unchanged.

Upload the contents of this folder to the repository root and replace matching files.
