# Bramha.org UI V5 — Clarity Pass

This pass focuses on crisp rendering in Windows/Edge:

- English UI no longer depends on Google-hosted Garamond/Noto Sans.
- Header, navigation, ticker and body use Segoe UI/system fonts for sharp ClearType rendering.
- Classical headings use Georgia/Times locally.
- Sanskrit and Telugu retain dedicated script fonts with local fallbacks.
- All text shadows are removed.
- Header spacing and navigation height are increased.
- Hero overlay is lighter and hero text is smaller/crisper.
- Reader English text is optimized for clarity.

No database, Supabase, publication, reader logic or Tarabalam calculation logic was changed.
