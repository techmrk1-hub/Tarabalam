# Bramha.org UI V8 — Sringeri Uniform Sister-Platform Shell

This version changes the brief from “Sringeri-inspired” to a uniform sister-platform design system.

## What changed
- One shared institutional shell across homepage and Śāstra/resource pages.
- Sringeri-style compact top strip, cream masthead, maroon navigation, dropdown rhythm and dense footer.
- Homepage follows the same portal hierarchy: featured media → three major portal entries → announcements → Connect with us.
- English UI uses crisp system fonts/Georgia; Devanagari and Telugu keep dedicated script fonts.
- Dharma/Gṛhya reader functionality and Supabase queries are unchanged.
- Tarabalam calculation engine is unchanged; only its outer Bramha.org shell remains themed.
