# Bramha.org UI V4 — Sringeri-style page rhythm

This release changes the homepage from a card/dashboard layout to an immersive institutional layout inspired by the page rhythm of sringeri.net while retaining Bramha.org's own branding, code, images and content.

Highlights:
- Full-width photographic hero
- Large alternating editorial image/text sections
- Announcements section
- Library statistics moved below the editorial sections
- Larger institutional footer
- More editorial internal page title treatment
- Existing Supabase/data logic unchanged
- Tarabalam calculation logic unchanged
