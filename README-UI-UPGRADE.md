# Bramha.org — Sringeri-inspired UI Upgrade

This package redesigns the Bramha.org interface while preserving the current Supabase data, reader logic, Tarabalam calculations, and publication rules.

Upload the CONTENTS of this folder to the root of the existing GitHub repository and allow the matching website files to be replaced.

Keep existing repository-only files that are not in this package, especially:
- CNAME
- 1.jpg through 6.jpg
- favicon.png
- images/
- sitemap.xml
- about.html (until it is redesigned separately)

Main UI changes:
- warm ivory/tan textured background
- deep maroon and temple-gold palette
- traditional serif display typography
- Noto script fonts for Devanagari and Telugu
- announcement strip and formal masthead
- devotional navigation
- redesigned homepage portal cards
- redesigned Dharma/Grihya readers
- redesigned Search, Articles and Vedic Mantras pages
- Tarabalam restyled without changing calculation logic
- richer multi-column footer

Fonts are loaded from Google Fonts; no font files are bundled.
