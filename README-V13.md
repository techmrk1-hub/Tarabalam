# Bramha.org V13 — Sampradaya-inspired Clone

This version adapts the visual structure and learning-site rhythm of SampradayaVidya.org for Bramha.org, while keeping Bramha.org branding, text, images, Supabase integration and Śāstra verification rules.

## What changed
- Traditional learning-site header with Library utility bar and simple menu navigation
- Full-width CMS-controlled hero slideshow
- About Bramha.org section with four image cards
- Learning & Excellence section
- Explore Bramha.org study-path cards
- Four Pillars section
- Warm maroon / saffron / cream visual system based on Bramha.org branding
- Matching visual shell applied to existing inner pages
- Existing Dharma/Gṛhya/Vedic readers are preserved
- Tarabalam calculation logic is untouched
- Google Sheet/Supabase homepage slide integration remains active

## Deploy
Upload the CONTENTS of this folder directly to the repository root. Do not place the folder itself inside the repository.

Keep your existing root `1.jpg` through `6.jpg` if Tarabalam still references them.
