# Bramha.org — Sringeri-closer UI refinement

This package intentionally changes the visual direction to a photo-led institutional temple/knowledge portal style inspired by the interaction rhythm of sringeri.net while retaining Bramha.org identity, text, database logic and original generated visual assets.

Upload the extracted contents to the repository root. Do not upload the ZIP itself.

Key files changed:
- index.html
- assets/bramha.css
- assets/site.js
- assets/visuals/*
- dharma-sutra/index.html
- gruhya-sutra/index.html
- vedic-mantras/index.html
- articles/index.html
- search/index.html

Tarabalam calculation logic is not changed by this package.
