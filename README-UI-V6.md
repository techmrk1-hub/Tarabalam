# Bramha.org UI V6 — Institutional Portal Rebuild

This version abandons the dashboard/marketing-homepage rhythm and rebuilds the public shell around the information architecture and browsing rhythm of a traditional institutional portal: broad header navigation, full-width feature media, major content sections, announcement lists, exploration tabs, and a dense Connect footer.

Important:
- Original Bramha.org code and visual assets only.
- No Sringeri logo, source code, text, or copyrighted images are included.
- No Supabase schema/data changes.
- No additional Sutra verification/publishing changes.
- Tarabalam calculation logic is unchanged.
